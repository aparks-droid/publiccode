I am following the How to AI Company Brain recipe. Help me clone and run my own copy locally, connect my own sources and customize it. My company data belongs in my own Supabase project. The instructor's hosted site is only a sample preview.

## Work with me

Run commands and inspect the result. Ask me only for actions that require my account or choices. Never ask for keys in chat or print them. I enter keys directly in the local app. Don't create paid resources or upgrade plans without my approval. Don't replace an existing project or erase my data.

## 1. Start my copy

Clone https://github.com/how-to-ai-co/company-brain.git into my chosen project folder. Read README.md and AGENTS.md. Confirm Node.js 22+ and npm are available. Run `npm install`, then `npm run dev`. Open http://127.0.0.1:3000. No Vercel deployment is required.

If I cannot access the private repo, have me request access from the How to AI organization; don't create an unrelated substitute.

## 2. Connect my database

Use my own Supabase project. For a new database, apply `supabase/setup.sql` once. For an existing installation, inspect migration history and apply only missing migrations; never reset it. Have me enter its URL and secret/service-role key in the local app's database form. Verify the app reports my project connected and the database denies anonymous access.

## 3. Connect a real source

Ask which source I use: Slack, Attio, or Stripe. Open its Connect form in Sources and follow the displayed permissions and coverage instructions. I enter its read credential directly. Click Connect & sync, then verify that actual records and source links appear. Reload and confirm the connection and records persist.

If the provider refuses access, fix the stated scope/key problem. Do not load sample data and call that a successful real connection. Samples are optional and labeled.

## 4. Connect AI and prove it

Have me enter my OpenAI or Anthropic API key under Connect AI. Explain that a test and future calls use API billing. Wait for a successful connection check. Ask a question whose answer is visible in an imported record; verify the answer cites that evidence. Check a follow-up question too.

Run Analyze, review its cited evidence, and mark an issue resolved to check the workflow. If the imported records have no actionable issues, an empty attention list is valid.

## 5. Set attention guidelines

In Sources, describe what matters to my business: examples include failed payments over a chosen amount, imminent customer commitments or stalled important deals. These are AI guidelines, not guaranteed deterministic rules.

Let me choose whether to enable automatic checks and their interval. The app and local monitor must remain running on my computer. Confirm the local monitor status and show me the result of a Sync & analyze now run. Don't claim unattended monitoring works until an enabled check completes.

## Finish

Report my local app URL, my Supabase project, which real sources actually synced, record counts, whether the AI answer succeeded, and whether recurring checks ran. State any pending verification plainly. Then help me customize this copy for my company.
